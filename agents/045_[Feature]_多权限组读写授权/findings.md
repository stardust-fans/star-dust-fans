# 调研发现

- deploy.yml 检查 .github/ 的任意改动和 test/ 存量文件修改或删除，请求非 bot 且非作者的仓库贡献者评审，并写入 CI 评论。不是站内 RBAC。
- 原权限是 role + 模块列表，没有 read/write，也没有多组成员。
- 菜单已有 can(scope) 过滤，但页面写入按钮未按权限隐藏，路由档案未加载时放行。
- 评论删除接口存在管理员分支但前置用户鉴权使其不可达；已按明确的 comments:write 授权支持管理操作，保留用户删除自己评论的契约。

- 首轮组合测试暴露旧角色测试夹具、缺失测试写入凭据和误授评论权限；已交子 agent 修正。
- 工具 schema 缺少既有迁移中的 comments/likes/forum 表，按既有迁移补齐 schema，不新增生产迁移。
- D1 允许双引号字符串，SQLite 校验配置须与 D1 实际语法一致，避免误报。
