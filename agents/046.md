# 后台权限组预设决策

- 用户确认：区域按功能模块划分；普通用户指后台账号预设，不扩展现有网站注册账号体系。
- 普通用户不授予后台权限；各区管理员仅授予对应模块 write，依照共享契约包含 read。审核、评论、标签、致谢、安全审计和账号权限管理分别授权，可多组组合。
- 只读观察员仅查看内容模块，不默认查看待审内容、安全记录或账号成员关系；站点管理员拥有当前全部已知权限。
- 初始化工具一次生成完整组目录，初始账号只加入站点管理员组。后台从预设复制为新组，必须显式保存，不能覆盖或修改已有组。
- 沿用原草稿 PR，生产配置未就绪时不发布。预设不构成新的角色特判或隐藏授权，服务端仍只读取存储的组权限。
