# 管理员 Env 存储决策

- 用户明确仅迁管理员账号、角色和权限，其他配置不变。
- 采用 EdgeSonic 同类 Workers Secret API 写入机制，ADMIN_ACCOUNTS 是唯一账号来源；不引入数据库 fallback、自动迁移或新绑定。
- 使用 nextId 保留整数 ID 单调递增，避免删除后重用 ID 导致旧 token 认证到新账号。普通管理员使用显式权限数组，不保留 null 全权兼容。
- 生产 Secret 尚未配置核验；main ruleset 要求 PR，仓库自动合并工作流还会自动部署。为避免管理员锁定，交付草稿 PR，配置齐备后再转为可合并。
- Secret 为整份快照，Cloudflare 部署传播与同时写入覆盖是所选存储模型的实际限制，已在配置说明中明确。
- 在 Windows 上使用 C:/Users/User/.codex/worktrees/stardust-fans 作为用户 ~/.codex/worktrees 约定的本机映射。
